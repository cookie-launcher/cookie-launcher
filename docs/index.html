Deneysel: imzasız ve notarize edilmemiş

macOS paketleri Apple Developer sertifikası olmadan derlenir; bu yüzden macOS Gatekeeper "geliştirici doğrulanamıyor" uyarısı verir. Bu bir virüs işareti değil, imza eksikliğidir. İlk açılışta aşağıdakilerden birini yapmak zorunludur:

⚠️ Sağ tık → "Aç" yöntemi macOS 15 (Sequoia) ve sonrasında artık çalışmıyor. Aşağıdaki iki yoldan birini kullanmalısınız.

  1. Hızlı yol (Terminal): DMG'yi açıp uygulamayı /Applications'a taşıyın, sonra Terminal'de şunu çalıştırın:
    xattr -dr com.apple.quarantine /Applications/CookieLauncher.app
  2. Arayüzden: uygulamayı açmayı deneyin → uyarı gelince Sistem Ayarları → Gizlilik ve Güvenlik bölümüne inin → güvenlik bildiriminde "Yine de Aç" → çıkan pencerede tekrar Aç.

Neden imzalı değil? Apple Developer Program üyeliği 99 $/yıl ve bunu karşılayamıyorum. Uygulama tamamen açık kaynak (GPL-3.0); istemeyen kaynak koddan kendisi derleyebilir.

Paketler GitHub Actions'ın macOS runner'larında üretilir. Geliştiricinin elinde Mac donanımı olmadığı için çalışma zamanı test edilmemiştir; sorun yaşarsan Issues'a bildir.
